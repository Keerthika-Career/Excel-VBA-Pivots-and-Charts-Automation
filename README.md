# 📊 Excel VBA Pivots and Charts Automation

## 🔹 Overview
This project is an automated Excel dashboard built using VBA.  
It generates Pivot Tables and Charts from raw data with a single click.

---

## 🔹 Features
- Automated Pivot Table creation
- Dynamic Charts (Pie, Column, Bar, Line)
- Employee performance analysis
- Sales analysis by employee and region
- Clean and formatted dashboard

---

## 🔹 Tools Used
- Microsoft Excel
- VBA (Visual Basic for Applications)
- Pivot Tables & Charts
